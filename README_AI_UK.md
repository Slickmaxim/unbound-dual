# Контекст для продовження роботи

Проєкт: gpSP 3D + read-only вкладки PokeDaisy для Unbound 2.1.1.1 EN.
Вихідні дерева й ліцензії описані в THIRD_PARTY_NOTICES.md та AGENTS.md.
Збирати лише PokeDaisy (`make -C 3ds 3ds`), native не збирати.
Картка тренера без значків; пошук оригінальних спрайтів ROM не завершений.
Оригінальні налаштування gpSP та кеш ROM збережені.

Для відтворення помилок потрібна точна CIA та відповідний ELF тієї ж збірки.
Crash dump не публікувати. Нова splash-збірка Luma з невірною версією 0.0.0
може змінювати вибір cache-flush шляху gpSP; ця причина ще не підтверджена
порівнянням на консолі. Не називати це доведеним дефектом.

Based on PokeDaisy by Lidor Itzhari - https://github.com/lidor30/pokedaisy

Гілка feature/spanish-v108: ES v1.08 + перемикач інтерфейсу English/Español. Дивись docs/SPANISH_SUPPORT_UK.md. Додано окремі профілі sinza та ES 2.1.1.1 з точними SHA-1 і власними текстовими таблицями; користувач підтвердив роботу всіх трьох ROM на консолі. Виправлення оформлення команди та відновлення неповного кешу також підтверджено користувачем на 3DS. Не вмикати інші ES ROM лише за схожістю: таблиці активних форм/предметів перенесені. Тестовий CIA 0.0.9; реліз не публікувати до перевірки save на консолі.

Fast forward: Max прибрано, старе ff_speed=0 стає 1 (2x); значення 1/2/3 лишилися 2x/3x/4x. Малий індикатор у верхньому правому кутку гри працює через обидва шляхи виведення, без оновлень нижнього екрана. Логіка/CPU bitmap у source/fast_forward.h; перевірка test/fast_forward_test.c. Нова функція потребує перевірки на консолі.
